# ✊ PIEDRA, PAPEL O TIJERA ✂️ — INTERFAZ CIBERNÉTICA

¡Bienvenido al desafío definitivo de Piedra, Papel o Tijera! Este proyecto es un juego interactivo desarrollado para entornos web que combina una estética futurista de neón parpadeante (estilo HUD Gamer) con un sistema inmersivo de audio y voz automatizada.

## 🎮 Modalidades de Juego
El juego cuenta con un menú principal interactivo que incluye las tres opciones requeridas:
1. **Opción 1 - PC vs Usuario:** Enfrentamiento directo contra la inteligencia de la computadora.
2. **Opción 2 - PC vs Usuario Aleatorio:** El sistema selecciona de forma imprevista e independiente si juega el Usuario 1 o el Usuario 2 contra la PC.
3. **Opción 3 - Usuario 1 vs Usuario 2:** Modo multijugador local en la misma pantalla. Las jugadas se procesan de forma oculta en variables para garantizar la transparencia del juego.

---

## 🛠️ Tecnologías Utilizadas
Para el desarrollo de este ecosistema se utilizaron herramientas nativas de desarrollo frontend, garantizando una carga rápida y compatibilidad total:
* **HTML5:** Estructuración de las pantallas, contenedores semánticos y componentes de video.
* **CSS3 Avanzado:** Diseño responsivo (adaptable a celulares), estilos holográficos con efecto de cristal esmerilado (*Glassmorphism*), fuentes de ciencia ficción (`Orbitron` y `Rajdhani`) y animaciones dinámicas de rebote y degradados en movimiento.
* **JavaScript (Vanilla JS):** Lógica del juego, algoritmos de selección aleatoria y sistemas de conteo de puntajes.
* **Web Audio API:** Generación programática de ondas de sonido de baja fidelidad para efectos y música ambiental synthwave en tiempo real.
* **Web Speech API (`speechSynthesis`):** Sistema de voz sintética en español para cantar los ganadores de cada ronda por los altavoces.

## 👨‍💻 Instrucciones de Uso
1. Abre el enlace del juego.
2. Activa la música si deseas una experiencia más inmersiva utilizando el botón amarillo.
3. Selecciona una de las 3 modalidades del menú principal.
4. Realiza tu ataque presionando los botones de comandos electrónicos (Piedra, Papel o Tijera).
5. Escucha los resultados y sigue tu score en el panel de control. ¡Puedes reiniciar la partida en cualquier momento!
